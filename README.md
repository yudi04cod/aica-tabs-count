My honest count of open browser tabs for make.fun's "How Many Tabs Do
You Have Open?": 47 — two browser windows, one full of documentation
and half-read articles, the other of things opened "just for a second"
and never closed. Surprising enough to raise an eyebrow, ordinary
enough to be true.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the count
(digits only, 1–5 characters), and writes the same bytes on every run.
